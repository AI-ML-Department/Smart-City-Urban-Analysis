Smart City & Urban Analysis
📌 Project Overview
In this project, you will explore data related to citizens' daily activities in a Smart City.
The goal is to understand urban lifestyle patterns through data analysis and visualization.
You will work with a dataset containing information about citizens, transportation, energy consumption, physical activity, and daily habits.
Important: This challenge focuses ONLY on Data Preparation and Exploratory Data Analysis (EDA). You must NOT apply any Machine Learning or Unsupervised Learning algorithms.
📂 Dataset
Dataset: Futuristic Smart City Citizen Activity Dataset
Download: https://www.kaggle.com/datasets/atharvasoundankar/futuristic-smart-city-citizen-activity-dataset

🛠️ Part 1 – Data Loading
Import the required Python libraries.
Load the CSV dataset using Pandas.
Display the first 5 rows.
Display the last 5 rows.
Check the number of rows and columns.
Display column names and data types.

🔍 Part 2 – Data Exploration
Explore the dataset using Pandas.
Display basic statistical information using describe().
Check the number of unique values in each column.
Identify numerical and categorical features.
Check the distribution of categorical variables.
Explore relationships between different features.

🧹 Part 3 – Data Cleaning

Investigate and handle data quality issues.
Check for missing values using isnull().
Calculate the percentage of missing values.
Identify duplicated rows.
Check for incorrect data types.
Check for inconsistent categorical values.
Detect possible outliers.
Handle the identified issues and justify your decisions.

📊 Part 4 – Data Visualization

Create at least 5 visualizations using Matplotlib and Seaborn.
Suggested visualizations:
Age Distribution: Histogram showing the distribution of citizens' ages.
Transportation Analysis: Bar chart showing the most commonly used transportation modes.
Energy Consumption: Boxplot showing the distribution of home energy consumption.
Lifestyle Analysis: Scatter plot comparing sleep hours and steps walked.
Carbon Footprint: Boxplot or histogram showing carbon footprint distribution.
Correlation Heatmap: Explore correlations between numerical variables.
For every visualization, write 2–3 sentences explaining what you observe.

⚙️ Part 5 – Data Preprocessing

Prepare the dataset for future analysis.
Encode categorical variables where appropriate.
Select relevant features for urban activity analysis.
Apply feature scaling to numerical features.
Explain why scaling is important when comparing variables with different units.
Save the cleaned dataset as smart_city_cleaned.csv.
Important: Keep a copy of the original dataset. Do not overwrite it.
